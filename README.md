# Linux-hands-On
Hands-on practice covering important Red Hat Linux commands and Bash scripting concepts.

Topics Covered
Functions — writing and calling Bash functions, passing arguments
Cron Jobs — scheduling automated tasks with crontab
Task Automation — automating routine admin tasks using Bash scripts
Loops — for, while, and until loops in shell scripting
User Input — reading input from the user with read
User Permissions — managing users, groups, and file permissions (chmod, chown, useradd, usermod)
Environment

RHEL, Bash
